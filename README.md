# 高三47班成绩查询

纯前端静态站点，可用 GitHub Pages 托管。学生用「姓名 + 身份证号」查询；身份证号在浏览器内做 SHA-256 后与 `data.json` 中的 `idHash` 比对，**站点文件不含明文身份证**。

## 文件

| 文件 | 说明 |
|------|------|
| `index.html` | 页面结构 |
| `styles.css` | 样式（含 iPhone / ≤640px、≤430px 手机适配） |
| `app.js` | 查询、渲染、趋势图、进退步看板、家长提示、PNG 下载 |
| `data.json` | 成绩数据（仅哈希，无明文身份证） |

## 本地预览

在本目录启动任意静态服务，例如：

```bash
cd score-site
python3 -m http.server 8080
```

浏览器打开 http://127.0.0.1:8080/

> 请用 HTTP 打开，不要直接用 `file://`（`fetch('data.json')` 在部分浏览器会失败）。

## 发布到 GitHub Pages

1. 推送到仓库默认分支（本仓库为 `master`）。
2. 仓库 **Settings → Pages**：
   - Source：`Deploy from a branch`
   - Branch：`master` / `/ (root)`
3. 保存后等待一两分钟；若已部署过，刷新页面或强刷缓存即可看到新功能。

也可使用 GitHub Actions 的静态站点工作流；本站无构建步骤，直接托管即可。

## 功能说明

- 首页输入姓名与身份证号查询
- 成功后展示：
  1. 第二次综合考试成绩单（各科大号分数、级排、校方向进退步）
  2. **总分趋势图**（Chart.js，最多 10 次有效总分，拐点标注分数）与 **级排趋势图**（Y 轴反转，名次越小越好，拐点标注级排）
  3. **进退步看板**（进步绿 / 退步红；英语生含听说与英语笔试；日语生含日语）
  4. **给家长的阅读提示**（根据趋势与进退步自动生成 3–6 条建议）
  5. 成绩履历表
- 「下载整页成绩图」将查询结果区域（含上述新区块）导出为 PNG（html2canvas CDN）

手机端（约 375–430px，含 iPhone 17 Pro 逻辑宽 ~402）已单独收紧字号、间距与图表标注，避免偏大、留白过多。

## 隐私

- `data.json` 仅存姓名与身份证 SHA-256（小写 hex）
- 禁止把明文身份证写入仓库或站点文件
